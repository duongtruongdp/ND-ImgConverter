# ND Image Converter v0.9.1

## Fixed

- Fixed bundled Media Engine detection on installed Windows systems.
- Corrected Windows executable path resolution for FFmpeg, FFprobe, yt-dlp, gallery-dl and the PO-token provider.
- Fixed Windows runtime verification for Tauri's packaged binary layout.
- Corrected extended-length Windows path handling in installed-app acceptance tests.

## Improved

- More reliable runtime health checks and diagnostics.
- Improved cross-platform packaging verification.

## Notes

- Media Engines are included in the installers. No separate FFmpeg, yt-dlp or gallery-dl installation is required.
- Existing Media Downloader, Video to GIF and conversion workflows are preserved.
- macOS packages are ad-hoc signed and not notarized. Windows Authenticode signing is not configured.
- Verify `SHA256SUMS.txt` before opening an installer.
- Media Engine Updates remain disabled until the trusted publisher configuration is enabled.
