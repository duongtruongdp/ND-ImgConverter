# ND Image Converter v0.9.0

v0.9.0 expands ND Image Converter from a local image utility into a broader media toolkit while keeping conversion local-first.

## Highlights

- Multi-URL video and audio downloading with format-aware selection.
- Playlist and gallery workflows with a persistent download queue.
- Optional browser-cookie authentication that is never enabled implicitly.
- Faster Video to GIF trimming with a compact geometry-based timeline.
- Bundled FFmpeg, FFprobe, yt-dlp, gallery-dl and companion runtime checks.
- Separate signed Media Engine update infrastructure with atomic activation and Restore Previous.
- OS-specific release installers for macOS Apple Silicon, macOS Intel and Windows x64.
- Application update notices that select the matching release installer when it is present.

## Distribution notes

- v0.9.0 application packages are currently ad-hoc/unsigned and not notarized; Windows Authenticode is not configured.
- Verify `SHA256SUMS.txt` from the GitHub Release before opening an installer.
- Media Engine Updates are a separate trust domain and are not enabled by this application release without a configured trusted publisher.
- Direct in-app installation of application updates is reserved for a later build with a Tauri updater signing key and compatible public key embedded in the app.
