# M3.5 release candidate audit

Audit scope: v0.9.0 source integration, native Windows CI packaging, release
candidate QA and safe integration into `main`.

## CI release behavior

The release workflow is now limited to pushes on `main` and manual dispatch.
It builds macOS arm64, macOS x86_64 and Windows x64 artifacts, uploads them as
short-lived internal Actions artifacts, and does not create or publish a
GitHub Release. Runtime source verification, binary manifests, package
verification and packaged media smoke tests are mandatory.

Windows CI additionally performs a silent NSIS install, verifies the installed
runtime layout, launches the installed executable, runs the packaged media
smoke test, and attempts silent uninstall. This is disposable CI validation;
it is not a substitute for signed production distribution or an independent
clean-machine GUI review.

## Remaining release gates

- Native Windows x64 CI execution and installer evidence.
- Native macOS Intel CI execution.
- Manual Tauri GUI acceptance for queue cancellation/retry/recovery and
  Video-to-GIF workflows.
- Developer ID/notarization and Windows Authenticode credentials.
- Full legal review and bundled upstream license texts.
- Redirect/DNS SSRF hardening review.

The release candidate is internal and unsigned until those gates are closed.
