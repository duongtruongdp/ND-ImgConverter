# M2.7 production binary readiness

Audit date: 2026-11-01

## Selection

The first approved local candidate is Martin Riedl's FFmpeg Build Server release 9.0.2. The publisher provides separate macOS arm64 and x86_64 ZIPs containing one executable each, published SHA-256 files, open build scripts, signed macOS binaries and a documented codec/build inventory. FFmpeg's official download page identifies this class of macOS static build as a third-party executable source; it does not claim that the publisher is the FFmpeg project.

The selected build reports GPL-enabled configuration. It is not treated as LGPL-only. Public redistribution still needs the publisher's notices/source offer and legal review of every enabled dependency.

## First real artifact

Produced locally:

```text
src-tauri/target/aarch64-apple-darwin/release/bundle/macos/ND Image Converter.app
```

The bundle contains genuine arm64 FFmpeg/FFprobe 9.0.2, yt-dlp, bgutil-pot, plugin resources, `runtime-manifest.json` and `resources/FFMPEG-NOTICES.txt`. The runtime verifier passed against the actual `.app`. The app-only Tauri build exited successfully after the final resource-manifest build.

The DMG bundler produced a DMG in an earlier resource build, but the final manifest build's DMG step failed in `bundle_dmg.sh` while this Mac had multiple unrelated disk images mounted. No external disk image was detached or deleted. The final M2.7 evidence is therefore the verified `.app`, not a distributable DMG.

## Smoke-test command

```bash
node scripts/smoke-test-packaged-runtime.mjs \
  "src-tauri/target/aarch64-apple-darwin/release/bundle/macos/ND Image Converter.app"
```

This uses only the binaries under `.app/Contents/Resources/binaries` and sets `PATH=/usr/bin:/bin`. It generated an H.264 fixture, probed it with bundled FFprobe, produced a palette GIF and extracted a still frame. It does not replace GUI clean-machine testing or queue-level app testing.
