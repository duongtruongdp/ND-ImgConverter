# M3.4 release stabilization audit

Audit date: 2026-11-01. Branch: `dev`. No commit, push or tag was performed.

## DMG stabilization

The failed Tauri build produced the `.app` but failed while running the bundled
`bundle_dmg.sh` Finder cosmetic AppleScript. Investigation found two stale
interstitial images belonging to this repository and several unrelated mounted
images from another project. Only the two ND Image Converter devices were
detached. A task-specific build using `--skip-jenkins --no-internet-enable`
then created and mounted a valid DMG.

The reproducible fix is [build-macos-dmg.mjs](../../scripts/build-macos-dmg.mjs).
It preserves the background resource, skips nonessential Finder automation,
checks `hdiutil imageinfo`, and prints the artifact hash.

Verified artifact:

`src-tauri/target/aarch64-apple-darwin/release/bundle/dmg/ND Image Converter_0.9.0_aarch64.dmg`

- Size: 136,380,875 bytes.
- SHA-256: `52b8c538eaf2345a6371dfba7ffa63cd9b5440cdd64b68ae6f911c6e137dbc74`.
- Mounted read-only; bundled app/runtime verifier passed; FFmpeg packaged
  smoke test passed; image detached after verification.

## Controlled fixtures

[create-media-fixtures.mjs](../../scripts/create-media-fixtures.mjs)
creates small H.264 videos, an audio/video sample, five images, Unicode and
duplicate filenames, and playlist-like files using the managed FFmpeg binary.
[media-fixture-server.mjs](../../scripts/fixtures/media-fixture-server.mjs)
serves direct image/media URLs, a slow endpoint, missing/invalid responses and
an explicit test-only JSON collection. It does not weaken production private-
address validation. `test-media-fixtures.mjs` ran the bundled gallery-dl
subprocess for five outputs, Unicode output, missing media and detached-process
cancellation.

## Cross-platform status

- macOS arm64: `.app` and DMG passed locally.
- macOS x86_64: source approvals and native CI build path prepared; no local
  Intel runner, app or DMG evidence.
- Windows x64: FFmpeg, FFprobe, yt-dlp, gallery-dl and bgutil source/hash
  records are now populated and source verification passes. No native Windows
  NSIS build or installed-app smoke test was possible on this Mac.

## Signing, legal and clean machine

No signing credentials are present. Developer ID Application, hardened runtime,
notarization/stapling, Authenticode and SmartScreen reputation remain blocked.
The third-party inventory identifies GPL FFmpeg/gallery-dl/bgutil obligations
and the remaining yt-dlp/PyInstaller notice work. A clean-machine checklist is
provided, but only the developer Mac and mounted DMG have been tested.

## Release decision

M3.4 is **PARTIALLY ACCEPTED**: macOS arm64 DMG stabilization is complete and
cross-platform source metadata is materially improved, but Intel/Windows
native artifacts, clean-machine acceptance, signing and GUI cancellation/retry
remain release gates.
