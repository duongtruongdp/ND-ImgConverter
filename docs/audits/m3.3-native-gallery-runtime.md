# M3.3 native gallery runtime and production package audit

Audit date: 2026-11-01. Branch: `dev`. No commit or push was performed.

## Gallery runtime

- Upstream: gallery-dl `1.32.19`, tag commit
  `e1322ffe8c0880d09ebeb43fd6531ed9bee25583`.
- Source archive: official Codeberg release asset; SHA-256
  `63323bc1bc37b8ba25c19d2ef7a86158d1f79cccaee8d69dda907986f3f3e824`.
- Build: native macOS arm64, Python 3.15.2, PyInstaller 6.22.3, one-file mode.
- Dependency installation uses `scripts/gallery-runtime/requirements-macos.lock`
  with `pip --require-hashes`.
- Artifact: Mach-O arm64, 14,748,160 bytes, SHA-256
  `6e92b8b29b3ff05d6c2d0cfc42cbff03eddbcfaf9420fd5eaa0d6ea2b8edbe66`.
- The PyInstaller build explicitly includes all source Python modules because
  gallery-dl discovers extractor modules dynamically; a version-only build was
  rejected after an isolated metadata smoke test exposed a missing extractor.

## Packaged app

The real app was built at:

`src-tauri/target/aarch64-apple-darwin/release/bundle/macos/ND Image Converter.app`

The app contains `Contents/Resources/binaries/gallery-dl`, its build manifest,
runtime manifest, GPL notice and the other managed media engines. The app
bundle verifier passed with `--require-downloader --require-gallery`. The
bundled executable was also run with `PATH=/usr/bin:/bin` and no Python or
Homebrew path: version check, bounded Wikipedia metadata preview and a real
image download passed. A GUI launch was observed as a live app process.

## Reliability evidence

- Selected gallery ranges now use gallery-dl's `--range` contract (`1,3`), not
  `--filter`, which is a file-filter and does not select gallery indices.
- A real public fixture produced one image and multiple image outputs. A Unicode
  destination path was used successfully.
- Rust cancellation is job-scoped and terminates the process group; startup
  recovery marks active persisted jobs interrupted and exposes retry. Full
  GUI cancellation/retry interaction still needs a manual desktop pass.
- The broad release gate remains blocked by missing approved yt-dlp/bgutil and
  Windows FFmpeg source records. DMG creation also failed locally in Tauri's
  `bundle_dmg.sh` after the `.app` itself was produced.

## License and release boundary

gallery-dl is GPL-2.0-only. The repository includes an attribution notice and
source/build provenance, but legal review of the combined distribution remains
required. The macOS artifact is a controlled project build, not an official
upstream native macOS binary.
