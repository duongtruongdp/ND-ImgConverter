ND IMAGE CONVERTER - INSTALLATION GUIDE (macOS)
===================================================================

Why does macOS say "The application can't be opened"?

Unsigned test builds may trigger a macOS Gatekeeper warning when downloaded.
Verify the release checksum before opening the app.

Recommended:
1. Drag "ND Image Converter" into your /Applications folder.
2. Right-click the app in Finder and select "Open", or use System Settings -> Privacy & Security -> Open Anyway.

Production signed and notarized releases should not require a Gatekeeper override.
